# 싱싱박스 교환/반품 정책

## 교환/반품 가능한 경우
1. 상품 품질 불량 (부패, 변질, 이물질 등)
2. 상품 파손 (배송 중 파손)
3. 오배송 (주문과 다른 상품 배송)
4. 수량 부족

## 교환/반품 불가한 경우
1. 단순 변심 (신선식품 특성상 재판매 불가)
2. 고객 보관 부주의로 인한 변질
3. 상품 수령 후 3일 초과

## 신청 방법

### 온라인 신청
1. 앱 또는 웹사이트 → 마이페이지 → 주문내역
2. 해당 주문의 '교환/반품 신청' 버튼 클릭
3. 사유 선택 및 사진 첨부 (필수)
4. 신청 완료 후 1영업일 내 처리

### 고객센터 신청
- 전화: 1588-1234
- 카카오톡: @싱싱박스

## 환불 처리

### 환불 소요 기간
- 카드 결제: 취소 후 3-5 영업일
- 카카오페이/네이버페이: 취소 후 즉시 ~ 3영업일
- 무통장입금: 환불 계좌 확인 후 3영업일 이내

## 자주 묻는 교환/반품 질문

Q: 사진이 없어도 환불 가능한가요?
A: 신선식품 품질 문제의 경우 사진 첨부가 필수입니다.

Q: 이미 먹은 상품도 환불 가능한가요?
A: 섭취 후 품질 문제를 발견한 경우, 남은 상품 사진과 함께 신청해주시면 확인 후 처리해드립니다.
