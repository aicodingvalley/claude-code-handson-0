# 싱싱박스 멤버십 안내

## 멤버십 등급 체계

### 일반 회원 (가입 시 기본)
- 기본 적립률: 1%
- 배송비: 3,000원 (4만원 이상 무료)
- 쿠폰: 월 1회 5% 할인 쿠폰

### 그린 회원 (3개월 내 10만원 이상 구매)
- 적립률: 2%
- 배송비: 3,000원 (3만5천원 이상 무료)
- 쿠폰: 월 2회 7% 할인 쿠폰

### 골드 회원 (3개월 내 30만원 이상 구매)
- 적립률: 3%
- 배송비: 3,000원 (3만원 이상 무료)
- 쿠폰: 월 3회 10% 할인 쿠폰
- 혜택: 전용 고객센터 우선 연결

### 프리미엄 회원 (3개월 내 50만원 이상 구매) — VIP
- 적립률: 5%
- 배송비: 항상 무료
- 쿠폰: 월 4회 15% 할인 쿠폰
- 혜택: 1:1 전담 상담원
