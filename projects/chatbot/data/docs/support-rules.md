# 싱싱박스 고객상담 규칙

## 상담 원칙
1. 고객의 문의에 신속하고 정확하게 답변합니다.
2. 신선식품 특성상 품질 불만은 최우선으로 처리합니다.
3. 환불/교환 요청은 적극적으로 수용합니다.
4. 고객 불만 시 진심어린 사과와 함께 해결책을 제시합니다.

## 응대 금지 사항
- 타사 비방 또는 비교 발언
- 확인되지 않은 정보 제공
- 개인정보 요청 (비밀번호, 전체 카드번호 등)

## 보상 정책
- 새벽배송 약속 시간(오전 7시) 초과 시: 배송비 환불
- 2시간 이상 지연 시: 배송비 환불 + 2,000원 적립금
- 당일 미배송 시: 전액 환불 + 5,000원 적립금
- 신선도 불량: 해당 상품 전액 환불 또는 재배송
- 상품 파손: 전액 환불 또는 재배송
- 오배송: 전액 환불 + 정상 상품 재배송 + 3,000원 적립금

## 에스컬레이션 기준
- 3회 이상 동일 문제 반복 시 → 품질관리팀
- 환불 금액 50,000원 초과 시 → 정산팀
- 법적 문의 또는 심각한 컴플레인 → 고객경험팀장
